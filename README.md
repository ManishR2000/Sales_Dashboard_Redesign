# Pre-sales dashboard redesign: UX case study

An interactive case study of how I redesigned the way a pre-sales team records work and reads performance: one connected product for Sales, Graphics and leadership, replacing a long request form, a weekly Excel export and a hand-rebuilt HTML report.

**View it live:** (https://github.com/ManishR2000/Sales_Dashboard_Redesign)

## What's inside

15 screens in five acts: Context, Problem, Thinking, Design and Impact. They cover the research, four turning points that changed the design, the decisions and trade-offs, the final screens and the results of a five-day team beta.

## How to view

- Click the left or right edge of the screen, use the ← → keys, or swipe on a phone.
- Click any screen image to open it full size.
- Works with the keyboard alone, and turns animation off if your device is set to reduce motion.

## About the content

All client names, people and data shown in the screens are fictional. The company logo is a placeholder.

## Built with

A single HTML file with inline CSS and JavaScript, no frameworks. The Manrope font loads from Google Fonts.
